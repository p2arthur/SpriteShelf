# Contributing to SpriteShelf

Thank you for your interest in contributing to SpriteShelf! We appreciate your help in making this project better.

## How to Contribute

- **Issues:** If you have ideas, feature requests, or find bugs, please open an issue on GitHub describing the problem or suggestion.

- **Pull Requests:** To contribute code or documentation improvements, fork the repository, make your changes, and submit a pull request.

- **Discussion:** Use issues to discuss proposed changes or ask questions.

## Guidelines

- Keep contributions focused and relevant to the project’s purpose.
- Follow clear, descriptive commit messages.
- Since this project is in early stages, there may not be automated tests or build processes yet.

## Code Style and Quality

Please write clear, maintainable code and documentation. We will provide more detailed guidelines as the project matures.

## Getting Help

If you need assistance or have questions, please open an issue.

Thank you for helping make SpriteShelf better!
