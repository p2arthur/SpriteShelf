# SpriteShelf

A proposal for organizing local game assets and keeping their source and license information easy to find.

This snapshot is documentation-only, with contribution guidance, a code of conduct, and an MIT license. The application and usage commands have not been implemented.

## Contribute to the proposal

Start with [CONTRIBUTING.md](CONTRIBUTING.md). The next useful contribution is a small implemented slice with documented inputs, outputs, and setup, rather than claims about features that do not exist yet.
