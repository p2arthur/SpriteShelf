# SpriteShelf

A simple local asset organizer for indie game developers to find sprites, textures, models, and audio, and track their sources and licenses.

## Purpose

SpriteShelf helps indie game developers organize, find, and track assets such as sprites, textures, models, and audio. The goal is to reduce time spent searching through folders and make each asset’s source and license easy to check.

This project starts with a small tool for managing local asset collections, with room for community contributions as it grows.

## Audience

This tool is designed primarily for solo indie game developers and small teams who manage their own asset collections and need a simple way to organize files and track sources and licenses. The initial focus is on hobbyists and game jam participants.

## Current Status

This repository currently contains the project scaffold and documentation. Implementation and usage instructions will follow as the project develops.
